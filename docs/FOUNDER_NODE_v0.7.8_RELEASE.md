# Founder Node v0.7.8

**Tag:** `founder-node-v0.7.8`  
**Download:** [GitHub releases](https://github.com/danishhaiderau-maker/doxed-founders-website/releases) · [Founder Den setup hub](https://doxxedcrypto.digital/founder-den?onboard=sovereign#founder-node-download)

## Highlights

- Recommended baseline for IDE workspace streaming, vault vector index rebuild, and hourly auto-update.
- Tray app reports `v0.7.8` in heartbeat and pairing status.
- Windows (.exe), macOS (.dmg), and Linux (.AppImage) installers published via CI on tag push.

## Install

1. Download for your OS from the setup hub or GitHub.
2. Launch from Start Menu / Applications / AppImage.
3. In Founder OS → Settings → Builder, generate **Code for desktop** and paste in the tray pairing dialog.
4. Run **Rebuild vector index** once on first pairing (up to ~2 minutes).

## Upgrade from v0.7.7

The tray menu checks for updates hourly. You can also download v0.7.8 manually from the links above.
