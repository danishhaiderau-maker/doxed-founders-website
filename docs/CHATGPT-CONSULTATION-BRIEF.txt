WHAT WE UNDERSTOOD — YOUR REFINED VISION
----------------------------------------

INVERTED STACK (TRUST FIRST, NOT LAUNCH FIRST)

The product stack flows in this order:

  Community → Trust → Founder OS → Raise Room → Launch Qualification → Token Infrastructure → Liquidity → Trading

We reject launch-first and Pump.fun-style anon deploy. Founders earn graduation. We compete with Product Hunt, GitHub, AngelList, Kickstarter, and YC — not meme coin factories.

RAISE ROOM IS A MANDATORY PATH

Every project follows:

  Founder → List Project → Trust Review → Community Validation → Raise Room → Launch Qualification → Launch

Nobody launches immediately. Eligibility is earned.

PROJECT MATURITY STAGES

  IDEA → BUILDING → VALIDATED → COMMUNITY → READY → LAUNCHING → TRADING → GROWING

These drive UX badges and discovery filters. We map from legacy database lifecycle enums until migration.

RENAME: TOKEN LAUNCH → FOUNDER GRADUATION

Graduation is an achievement when launch qualification gates pass. A composite Founder Score (Builder + Trust + Community + Scout + Build + Delivery) displays at unlock. It is not a one-click mint.

DDOLLAR REFRAME: PROOF OF CONTRIBUTION

DDollar is earned via reviews, scouting, building, and validation — not only spent. Paper Raise Room uses simulated dollars; real economic effect waits for counsel-gated phases.

COMMUNITY ALLOCATION BUCKETS (WEIGHTED, NOT EQUAL)

  Validators .............. 25%
  Scouts .................. 20%
  Builders ................ 20%
  Early Followers ......... 15%
  Paper Raise ............. 10%
  Bug Hunters ............. 10%

We reject equal 10% airdrops to all active users (supersedes old TOKEN-LAUNCH-TRADING-ECOSYSTEM-PROPOSAL equal-split section).

LAUNCH QUALIFICATION GATES (EXAMPLE THRESHOLDS)

  Min project followers ............... ≥ 25
  Paper conviction .................... ≥ $10,000 simulated
  Community validation score .......... ≥ 70% weighted
  AI / scam pass ...................... No active investigation
  Identity ............................ X linked OR verified email + wallet
  Founder Launch Score ................ ≥ 65 composite

FOUNDER EXCHANGE (NOT "DOXXED DEX")

Only graduated projects list. Trust metadata visible. Jupiter-routed swaps in Phase 3 with tier-based platform fees.

REGULATORY ENGINE

Founder questionnaire classifies: Community Project | Utility Token | Governance Token | Capital Raise | Restricted. Features gate per class. Capital Raise path requires consult AU counsel — we will not ship real raises without that.

AUSTRALIAN LEGAL SEPARATION (ENGINEERING FRAMING, NOT LEGAL ADVICE)

  Company ........... community / software platform
  Blockchain ........ settlement for user-initiated transactions
  Users ............. self-custody wallets; no platform custody in Phase 1–3

PLATFORM SNAPSHOT (FOR CONTEXT)
-------------------------------
Doxxed Crypto is a hybrid monorepo: Next.js 15 web on Vercel, NestJS API on Railway, Neon Postgres, optional Founder Node desktop vault. Public site: doxxedcrypto.digital. Raise Room: /raise-room. Trust Center and List Project gate who can open Proof Raise windows.

We serve three overlapping personas:
  • Scouts / community — discover projects, validate in Trust Center, paper trade, earn DDollar Proof of Contribution
  • Founders — build in Founder OS, list projects, earn launch qualification, open Proof Raise when eligible
  • Traders — paper desk, agent hub showcase, optional signal API (informational only; self-execute)

DDollar today is off-chain reputationPoints plus PointLedger — not an SPL token. Paper trading uses virtual USD with no brokerage relationship. SimulatedRaise debits paper cash for conviction signals; nothing moves on-chain in Phase 1.

COMPETITOR FRAMING (YOUR GUIDANCE)
----------------------------------
We position against Product Hunt (discovery), GitHub (build proof), AngelList (founder identity), Kickstarter (demand validation), and YC (milestone narrative) — not Pump.fun or anon bonding-curve deployers. Speed-to-coin is an anti-goal. Trust accrual is the moat.

MANDATORY PIPELINE — OPERATIONAL DETAIL
---------------------------------------
Step 1 — List Project: founder submits ListingApplication; community votes; admin approves; Project record created.
Step 2 — Trust Review: Trust Center categories, investigations, scout votes; weighted validation score.
Step 3 — Community Validation: validation signals on Raise tab (Phase 1 RR-003); sync with Trust Center.
Step 4 — Raise Room: founder opens Proof Raise only after launch qualification (Phase 1 RR-005); community commits paper conviction; 1% paper burn on allocation fee.
Step 5 — Launch Qualification: six gates (followers, paper $, community score, AI pass, identity, Founder Launch Score).
Step 6 — Founder Graduation: snapshot + export; composite scores displayed at unlock; allocation registration CSV.
Step 7 — Founder Exchange (Phase 3): graduated projects only; Jupiter swaps; trust metadata on pair pages.

FOUNDER SCORE COMPONENTS (AT GRADUATION UNLOCK)
------------------------------------------------
  Builder .......... GitHub, commits, verified builder tier
  Trust ............ Trust Center weighted validation, investigation status
  Community ........ Validation signals, follower engagement
  Scout ............ EarlyScoutRecord, scout accuracy (Phase 2 ScoutProfile)
  Build ............ Videos, build posts, Startup Genome transparency
  Delivery ......... Launch readiness, milestone completion

Overall Founder Launch Score 0–100 gates Proof Raise alongside the five other qualification checks.
