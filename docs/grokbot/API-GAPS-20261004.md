## Implemented route: `GET /api/monitor/integrity`
- **Auth**: Flask admin session/header (`X-Bot-Admin-Token`), OR `Authorization: Bearer <MONITOR_READ_TOKEN>`. Otherwise 401. Bypasses the global admin guard only for this path (same pattern as the digest). It works for admin use with no new secret.
- **Methods**: GET only. Paper-safe: no lock, no exchange call, no file write. The only I/O is one bounded 64 KB tail read at loop start (in the capture thread, not the route).
- **Size**: 16 KB budget, enforced by `monitor_api.fit_to_budget`.
- **Fields**
  - `process`: git_rev, boot_id, pid, process start, and allowlisted `FLY_*` identity (app, region, machine id, machine version, image ref, process group). No other environment values.
  - `tape_1s`: tracking start, last bucket, last-write age, restart `boot_gap` (seconds lost between the previous process's last bucket and this one's first), and per 1h/24h window: expected, written, missing, write_failures, stale_or_invalid, late_written, coverage_pct, gaps, longest_gap_sec, window_complete. Also `recent_gaps` (from, seconds, kind WRITE_FAIL/SKIP) and status OK / DEGRADED / GAPPY / STALLED / NO_DATA.
  - `ai_calls`: per 1h/24h: calls, ok, failed, success_rate, latency p50/p95/max (successful calls), error_classes (from `classify_ai_provider_error`), plus last failure time and class.
  - `fill_quality`: per research lane x liquidity (TAKER/MAKER): fills, fills_24h, and per horizon (1/10/60/300 s) `mean_mid_bps`, `mean_exit_touch_bps`, late_samples. Bounded at 2000 rows.
  - `research_freeze`: when PR #430's `_research_freeze_public` exists.
  - `verdict`: compact tape status, AI success rate and p95 for the last hour.
- **Hooks**: `microstructure_capture_loop` (prime and observe), `record_ai_provider_outcome`, and `_sample_execution_markouts` (FILL_MARKOUT rows). All are fetched with `globals().get`, so if the module fails to import, trading is unaffected and the route returns 503.
- **Caveat**: counters are in-process. They reset on restart, which is why `boot_gap` and `prior_process_last_bucket_utc` exist; `window_complete=false` until the window has elapsed since boot.
