WHAT THIS IS
------------
Doxxed Crypto is a crypto-native founder and community platform. It combines curated project discovery, a trust layer (List Project + Trust Center), a virtual economy (DDollar credits), paper trading, Raise Room demand validation, Founder OS (web command center for Copilot/build/deploy), Founder Node (desktop encrypted vault), and trading agents (paper desk + conservative BTC signal showcase).

Mission: surface legitimate projects with public founders — pro-accountability, pro-builder — not an anonymous memecoin factory.

Architecture is hybrid: public product data on Neon Postgres; private founder data (memory, sealed API keys) with optional Founder Node zero-knowledge relay; NestJS API on Railway as control plane; external workers (LLMs, Cursor, GitHub, Vercel) connected via BYOK.

RATE LIMITING & ABUSE (July 2026 patches)
-----------------------------------------
Internal audit found AI endpoints could bypass limits when Neon DB unreachable (fail-open).
Patches: RATE_LIMIT_FAIL_OPEN=false (fail closed → 503); atomic DDollar spend; extended Copilot limiter coverage; TWITTER_VERIFIED_FREE_TOKEN_GATE; PARASITE/BUILDER daily token caps; promo pool preservation for verified builders.
Layers: global IP throttler (100/min, in-memory per replica) + custom RateLimit table (userId+endpoint) + promo token cap aggregate + tier caps.
