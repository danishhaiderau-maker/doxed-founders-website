# Platform Verification Vision (digital twin)

**Status:** Vision / Phase 2+ — not fully implemented  
**Last updated:** 7 July 2026

## Goal

A **verification layer** that ties founder claims to observable signals: GitHub activity, build posts, paper conviction, trust reports, regulatory class, and launch qualification — surfaced as a coherent “digital twin” for scouts and admins.

## On master today

- Phase 1.5 trust layer (`PHASE_15_TRUST_LAYER_ENABLED`) — regulatory gates, LQ score, progressive unlock
- Observatory (`OBSERVATORY_ENABLED`) — subsystem health probes at `/admin/observatory`
- Raise Room discovery hub — paper conviction + validation cards + leaderboards (product slice)
- Demo Mode — seeded ecosystem for smoke / xlarge demos

## Still missing (future work)

1. Unified **founder verification profile** page merging attestation + GitHub + KYC status
2. Merkle / on-chain proof export for whitelist commits (Raise Room Phase 2)
3. Automated **anomaly flags** when twin signals diverge (e.g. high LQ, zero build posts)
4. Public **verification badge** API for embeds
